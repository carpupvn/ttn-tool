# TTN Save Editor

Công cụ chỉnh mã sao lưu cho game **Tiệm Trà Nhỏ**. Chạy hoàn toàn offline
trong trình duyệt, deploy trên GitHub Pages.

## ⚠️ Tuyên bố miễn trừ

- Công cụ **không chính thức**, không liên kết với tác giả game.
- Không dùng để gian lận trong môi trường cạnh tranh.
- Người dùng tự chịu mọi rủi ro.
- Nếu tác giả game yêu cầu gỡ, repo sẽ được gỡ.
